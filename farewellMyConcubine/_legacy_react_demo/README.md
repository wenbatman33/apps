# 霸王別姬展示頁交付包

## 開啟方式

請在此資料夾啟動靜態伺服器，不建議直接雙擊 `index.html`，因為展示頁會載入本機素材路徑。

```bash
cd 霸王別姬_展示頁交付包
python3 -m http.server 5178
```

開啟：

```text
http://localhost:5178/
http://localhost:5178/#presentation-lab
```

## 內容

- `index.html`：展示頁入口。
- `assets/`：打包後的網頁程式與樣式。
- `美術製作/assets/`：遊戲美術素材。
- `docs/`：遊戲說明與素材需求文件。
