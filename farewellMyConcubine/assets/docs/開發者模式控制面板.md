# 開發者模式控制面板

使用方式：

```text
http://localhost:5173/?dev=1
```

只有網址帶 `?dev=1` 時，遊戲畫面右側會出現 DEV MODE 控制面板。

---

## 控制項

### RTP 顯示

用途：顯示測試用 RTP 目標值。  
目前作為數值觀察與調校標記，不代表正式後端數學模型。

### 命中加成

用途：提高一般賠付符號的相對權重。  
可用來快速測試盤面連線、消除、故事命數增加的節奏。

### 鳳凰令機率

用途：提高 Scatter / 金 Scatter 權重。  
可用來測試 Free Game 觸發頻率。

### 天命玉機率

用途：提高天命玉出現機率與數量。  
可用來測試倍率成長、快爆訊號、Big Win 以上演出。

## 功能按鈕

| 按鈕 | 功能 |
| --- | --- |
| 進 FG | 直接進入虞姬覺醒 Free Game |
| 退 FG | 退出 Free Game 回到楚漢戰局 |
| BIG | 播放 Big Win 演出 |
| SUPER | 播放 Super Win 演出 |
| MEGA | 播放 Mega Win 演出 |
| JACKPOT | 播放 Jackpot / 天下歸一演出 |
| 幕初逢 | 跳到第一幕 初逢 |
| 幕爭姬 | 跳到第二幕 爭姬 |
| 幕四面楚歌 | 跳到第三幕 四面楚歌 |
| 幕霸王別姬 | 跳到第四幕 霸王別姬 |
| 天下改命結局 | 直接將命數設為最高並播放天下改命結局 |

---

## 注意

這些控制是前端開發測試工具，用來調整體感、驗證演出與故事流程。正式版 RTP、RNG、Free Game 觸發率、Jackpot 機率應由後端遊戲數學模型控制。
