# 霸王別姬故事美術素材需求

版本：v0.1  
用途：呈現 12 分鐘「霸王別姬命局」所需的場景、角色、UI、Spine、特效與結局素材。

---

## 1. 整體美術方向

### 核心氣質

這款遊戲不是單純戰爭題材，而是一場帶有宿命感的楚漢悲劇。畫面要讓玩家感覺自己正在看一齣華麗、危險、即將走向離別的戲。

關鍵詞：

- 楚漢戰場
- 霸王別姬
- 虞姬鳳火
- 玉璽改命
- 烏江悲歌
- 劉邦與項羽爭奪命局

### 色彩基調

| 角色 / 勢力 | 主色 | 副色 | 用途 |
| --- | --- | --- | --- |
| 項羽 / 楚 | 黑、赤紅、暗金 | 火光、戰鼓紅 | 霸王氣勢、悲劇、戰場 |
| 虞姬 | 鳳紅、金、粉玉 | 薄紗白、暖光 | 鳳火、舞姬、命運 |
| 劉邦 / 漢 | 青金、玉白、冷藍 | 帝王金 | 謀略、玉璽、對立勢力 |
| 命數 / 改命 | 白金、鳳凰金 | 高亮紅金 | 大贏、改寫結局 |
| 烏江悲劇 | 黑藍、冷灰、殘紅 | 月光白 | 失敗結局、離別 |

## 7. 製作優先順序

### P0：先讓故事成立

1. 四幕背景各 1 張。
2. 三角色基礎立繪。

4. Free Game 鳳火插入背景。

1. 虞姬 Spine 第一版。
2. 項羽 Spine 第一版。
3. 劉邦 Spine 第一版。
4. 四幕前景粒子。

### P2：營運級 polish

1. 每幕角色差分造型。
2. 結局專屬 Spine 動畫。
3. 玉璽冊完整 UI。
4. 章節轉場動畫。
5. 大贏改命演出。

## 8. 驗收標準

- 不看文字也能感覺四幕情緒有變化。
- 虞姬在 Free Game 中必須成為畫面核心。
- 項羽在第四幕必須有明確離別感。
- 劉邦在第二、三幕必須有壓迫感。
- 低命數結局要悲劇，高命數結局要明顯改命。
- 快爆訊號不能只是 UI 文字，盤面光效也要變強。
- 所有背景中間要保留 6x5 盤面位置，左右保留角色 Spine 空間。
