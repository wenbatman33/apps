          素材建置規劃

          先把遊戲可視素材拆成明確清單，後續每一項都應交付真實圖檔，不使用程式繪製色塊代替。

          場景與背景

          • 主遊戲背景已具方向
          • Free Game 背景已具方向
          • 爆獎舞台背景已具方向
          • 轉場光效層待補 PNG / WebP

          角色素材

          • 項羽立繪待補透明 PNG
          • 劉邦立繪待補透明 PNG
          • 虞姬立繪舊稿參考
          • 角色表情 / 特效版本待補

          轉輪與符號

          • 高倍率角色符號待補 sprite sheet
          • A/K/Q/J/10 低倍率符號待補
          • Wild / Scatter / Bonus待補
          • 符號中獎高亮待補序列圖

          介面與特效

          • 下注 / 自動 / 停止按鈕已具方向
          • 金額數字字型圖待補 bitmap font
          • Win / Big Win / Mega Win待補分層圖
          • 粒子與光束素材待補透明 PNG

          建議輸出規格

          畫面稿維持接近 1672 x 941；可互動物件改用透明 PNG、spritesheet 或 atlas。命名建議統一英文小寫與用途前綴，方便 Phaser 載入。
