# 防守特洛伊

手機直屏、固定俯視角的單人 PvE 隨機召喚合成塔防遊戲。使用 Phaser 3、TypeScript 與 Vite 製作，邏輯畫布為 720 × 1280，會自動縮放至手機螢幕。

## 啟動

```bash
npm install
npm run dev
```

正式建置：

```bash
npm run build
npm run preview
```

## 目前可玩內容

- 封面、序章、主城、英雄、軍團、十年戰役、戰前、戰鬥與結算的完整流程。
- 中央固定 3 × 5、共 15 格的單人棋盤；敵軍從海岸傳送門出現，沿棋盤外圍行軍至特洛伊城門。
- 玩家消耗法力隨機召喚五張兵種卡之一；棋子會隨機落在空格，召喚費逐次提高。
- 相同兵種且相同星階才能合成；合成後升一階，結果兵種從五張牌中重新隨機。
- 棋子不可任意移到空格，拖曳只用於合成；也支援依次點選兩個有效棋子。
- 底部五張卡可消耗法力進行本局全體強化；合成階與卡牌強化等級互相獨立。
- 五種兵種固定使用黃、紅、紫、綠、藍職業光環，軍團、戰前、棋盤與底部卡牌的顏色完全一致。
- 英雄赫克托耳獨立於棋盤與兵種牌，怒氣充滿後可擊退全路、造成傷害並恢復一顆生命。
- 每年三波 PvE 敵軍與三次首領戰；普通兵、盾兵、年份首領，生命歸零或擊敗第三名首領後結算。
- 守軍會持續轉向最前方敵人；五個兵種各有待機、蓄力、出手、收招四格PNG攻擊序列，並搭配前衝回彈與職業光環脈衝。投射物會在「出手幀」才真正飛出，命中後顯示PNG爆點、受擊閃爍與浮動傷害數字。
- 每波採短間隔出怪並有機率追加小隊，形成密集怪群；相應降低普通怪生命值，增加場面密度而不只提高難度。
- 即時顯示分數、時間、波次、三顆生命、法力與英雄怒氣，結束後進入逐項結算。

## 第一次戰鬥操作

1. 進場立即連續點擊中央黃色「召喚」建立盤面；戰鬥會在 8 秒後自動開始，不會等待教學。
2. 前兩次召喚保證產生同一種一階守軍。把橘色棋子拖到綠色棋子，或依次點擊兩者完成合成。
3. 持續召喚、合成，並點擊底部五張卡升級同類兵種；不要只留下單一棋子。
4. 赫克托耳怒氣達 100% 後，點右下角英雄肖像施放「不破城牆」。

所有遊戲可視素材均由實際 PNG 圖檔載入；專案沒有使用 Phaser Graphics、Canvas、程式幾何圖形或 SVG 充當角色、場景與 UI 素材。
