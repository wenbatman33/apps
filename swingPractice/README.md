# 全壘打王 HOMERUN KING ⚾

Three.js 打造的 3D 全壘打揮擊比賽，**室內巨蛋球場 ＋ 二頭身 Q 版球員**，PC 與手機（直屏／橫屏）皆可玩。無需 build，開 `index.html` 即跑。

## 玩法

- 投手投球，抓準時機**單鍵揮棒**（空白鍵／點畫面／右下大按鈕）
- 揮太早 → 拉打（右外野方向）；揮太晚 → 推打（左外野方向）
- 判定分 PERFECT / GOOD / 接觸 / 擦棒 / 揮空，初速與仰角由時機品質決定
- 球飛出去後鏡頭自動追球，越過全壘打牆即 HOME RUN，連續全壘打有 COMBO 加成
- **10 球挑戰**：固定 10 球比總分　·　**生存賽**：揮空 3 次結束

### 操作

| 動作 | PC | 手機 |
|---|---|---|
| 揮棒 | `空白鍵` / 點畫面 | 點畫面 / 右下「揮棒」鈕 |
| 強打模式 | `P` | 左下「💪 強打」 |
| 時機輔助 | `A` | 左下「🎯 輔助」 |
| 音效開關 | `M` | 左下「🔊 音效」 |
| 開發者工具 | `D` | 右側 ⚙ |

音效全部是 WebAudio 即時合成，無外部音檔：木棒擊球（噪音 burst ＋ 木頭共鳴）、揮空風聲、捕手手套、全壘打的上行勝利音。**沒有群眾歡呼與環境底噪**——那類效果用濾波白噪音合成聽起來只會像雜訊。

強打＝初速 +13%，但判定窗口縮到 74%。輔助模式預設開啟（顯示球種與時機條）。

## 排行榜

localStorage 本地榜，依難度分開記錄，保留前 30 筆（顯示前 20）。分數 = 全壘打 × (1000 + 距離×12) + PERFECT 加成 + COMBO 加成 + 場內安打距離分。

## DEV 微調工具（按 `D`）

所有數值即時生效，調完按「💾 匯出」會存進 localStorage 並印到 console／複製到剪貼簿，告訴我數值我再 bake 進原始碼。可調：

- **節奏**：每球間隔、全壘打後停留、**飛球播放倍速**、投球動作速度、倒數秒數
- **飛行物理**：空氣阻力、後旋升力、重力、順風／側風
- **揮棒判定**：PERFECT / GOOD / OK / 揮空窗口（ms）、棒頭延遲、輔助倍率
- **擊球**：初速上下限、最佳仰角、仰角亂度、拉打係數
- **球場**：兩翼／中外野距離、擊球點、好球帶高度
- **相機**：位置、注視點、FOV（PC／手機分開）、追球平滑、震動

另有「⚾ 測試擊球」（強制一發理想擊球看距離）與「📷 循環鏡頭」。

## 物理參考值

阻力係數 `0.0052`（終端速度 ≈ 43 m/s，接近真實棒球），實測：

| 初速 | 仰角 | 飛行距離 | 最高點 |
|---|---|---|---|
| 50 m/s (180 km/h) | 29° | 145 m | 28 m |
| 45 m/s | 29° | 124 m | 23 m |
| 38 m/s | 29° | 97 m | 17 m |

全壘打牆：兩翼 100 m、中外野 122 m、牆高 3.6 m（接近真實大聯盟球場）。

一發 145 m 的全壘打真實滯空約 6.6 秒，看起來很拖，所以擊出後**播放倍速 ×2.1**（`PACE.flightSpeed`）——只加快播放，物理積分照跑，落點與距離不變。

## 打擊視角

參考 MLB The Show 的近景側後方視角：鏡頭低而平（y≈1.45m）、擺在打者外側後方，視線直看投手。打者落在畫面右側約 73%（NDC x≈0.46）、全身入鏡，投手在畫面正中央。

- **不顯示捕手與裁判**——他們站在鏡頭與本壘之間會整個擋住視野（DEV 工具的「👤 捕手／裁判」可切回來）
- **好球帶白框**顯示在本壘板上方，輔助模式開啟時出現，是這個視角的主要瞄準參考
- 直屏另有一組偏移（`portraitX/Y/Z`），因為手機的水平視野窄，要退後並把打者往畫面內帶
- 擊中後鏡頭**停留 0.52 秒**（`PACE.swingHold`）讓你看完揮棒動作與火花，才切去追球

## 打擊感

打擊遊戲的爽度不是靠單一參數，是一串反饋疊起來的。擊中瞬間依序發生：

1. **頓幀** `PACE.hitstop`（0.075s × 品質）——畫面先卡住那一下，這是衝擊感的主要來源
2. **鏡頭縮進** `CAM.hitZoom`（FOV 縮 6 度後快速回彈）
3. **震動** `CAM.shake` ＋ **爆裂火花**（金＋白兩層粒子）
4. **慢動作** 0.4～0.65 秒，再恢復正常速度
5. 球以 `PACE.flightSpeed`（×2.9）飛出去

另外每次出棒都會播風聲（不只揮空時），才聽得出「確實揮了」。

**揮棒動畫刻意放慢**（`SWING.swingSpeed = 2.6`）好看清楚出棒。這裡有個硬性約束：

> `SWING.barrelDelay` 必須等於 `contactAt / swingSpeed`（0.42 / 2.6 ≈ **162ms**）

barrelDelay 是判定用的提前量，contactAt/swingSpeed 是動畫掃到接觸幀的時間。兩者不相等，就會出現「球已經飛走、球棒才掃過來」的錯位。**改動畫速度時務必同步改 barrelDelay。**

同理，球是等揮棒動畫跑到接觸幀才真的飛出去（`executeHit()`），不是按下去就飛——後者會讓打擊完全沒有接觸感。

## 場景：室內巨蛋

白色膜結構圓頂（放射狀肋條＋同心環）、屋頂三圈燈組（58 盞）。

**看台是真正的階梯幾何**：26 階，每階「踏面（貼座椅圖）＋ 立面（水泥）」分開建，不是一片平滑斜面——平滑斜面遠看就只是一面藍牆。

**觀眾約 24,000 人**，每排沿弧長以 0.62m 間距排列（真實座位間距），每 46 個座位留 3 個當走道，另有 6% 隨機空位。每人只是**一個貼了人形剪影 alpha 貼圖的 quad**（2 個三角形，共約 48K 三角形，單一 draw call），朝向球場中心所以不必做 billboard。配色以白／灰／深藍為主、穿插少量鮮色——全用鮮豔色會像一堆糖果。

人浪動畫寫在 **vertex shader**（`onBeforeCompile` 注入 `uTime`／`uExcite`，依 instance 的方位角當相位），CPU 每幀只更新兩個 uniform，所以兩萬人一起跳也不掉幀。

草皮是一張 2048² 的烘焙貼圖（`fieldTexture()`），以本壘為圓心的同心弧割草帶為主紋、放射狀為輔，再逐像素加草絲質感；泥土有同心圓耙痕。整體亮度靠 Ambient 0.30 ＋ Hemisphere 0.72 ＋ 三盞方向光，不用夜間打光。

## 角色模型：目前用什麼、要換成什麼

**目前是程序化二頭身 Q 版角色**（實況野球那種比例）——`src/characters.js` 用基本幾何體組裝，比例是照參考圖對出來的：

- 身高 1.46m、**頭半徑 0.38m（頭佔身高 52%）**——頭不夠大就不像
- 軀幹半徑 0.20m，**要比頭明顯小**
- 腿極短（大腿 0.20 ＋ 小腿 0.18），鞋子誇張放大到幾乎只看得到鞋
- 手臂極短（0.13 ＋ 0.12），手掌是半徑 0.095 的**大圓球**，沒有手指
- 球棒長 0.95m、棒頭直徑 14cm——照真實比例做會細到看不見

黑豆眼＋眉毛＋腮紅，打者戴護耳頭盔、捕手有面罩護胸。骨架動畫全部手寫，雙手用近似 IK 跟著球棒握把跑。

### 球棒的握把位置是「掃描」出來的，不要憑感覺改

大頭角色最麻煩的是**球棒會被頭整個擋住**。握把位置 `(-0.25, 0.24, 0.50)`＋`rotation.x = 0.30` 是實際掃描 grip 的 x/z/rotation 組合、投影到畫面座標比對出來的解——這組讓棒頭在畫面上離頭 0.58 NDC（憑感覺調的版本只有 0.03，等於整支疊在頭上）。

改動角色比例或相機後，這個位置要重新掃描，掃描腳本的作法：對每組候選值設定 grip、`updateMatrixWorld`、把棒頭與頭 `project(camera)`，取兩者畫面距離最大且「棒頭高過頭頂 ＋ 握把在頭的靠鏡頭側」的組合。

### 揮棒軌跡拖尾

從打者背後看，球棒是指向鏡頭深處的，透視上只剩一小截。**揮棒感主要來自拖尾**（`makeSwingTrail`）：取棒頭與棒身中段兩點，累積 16 幀畫成 ribbon，用 AdditiveBlending 讓舊的一端自然淡出。沒有它，不管動畫做得多好都看不出有揮棒。

好處是造型討喜、揮棒節奏跟判定完全對齊、零下載、零授權問題。**這個風格用幾何體就能做好，其實不太需要外部模型**——但如果想要更精緻的角色：

### 換模型的實際步驟

1. 取得 **`.glb`**（GLTF 二進位，Three.js 原生支援；FBX 請先用 Blender 匯出成 GLB）
2. 放到 `assets/characters/`（例：`batter.glb`、`pitcher.glb`）
3. 告訴我檔名，我用 `GLTFLoader` + `AnimationMixer` 接進去，並把揮棒動畫的**接觸幀**對齊判定時刻（`SWING.barrelDelay`）——這步是關鍵，不對齊會出現「看起來揮到卻判揮空」

> 註：Mixamo 的 Baseball Hit 動畫接觸點約在整段的 40%，跟目前程序化角色的 `contactAt = 0.42` 幾乎一致，接起來會很順。

## 檔案結構

```
swingPractice/
├── index.html          # 版面、CSS、DOM（HUD／選單／結算／排行榜／DEV）

│   ├── stadium.js      # 巨蛋屋頂、草皮貼圖、內野、全壘打牆、看台、觀眾、記分板
│   ├── characters.js   # 二頭身 Q 版角色：打者／投手／捕手／裁判／野手＋骨架動畫
│   ├── ball.js         # 球：投球軌跡、變化球、擊球飛行積分、撞牆、拖尾
│   ├── game.js         # 流程狀態機、揮棒判定、計分、特效
│   ├── ui.js           # HUD、選單、結算、排行榜
│   ├── dev.js          # DEV 微調工具
│   └── sound.js        # WebAudio 合成音效（無外部音檔）
```

## 本機執行

```bash
python3 serve.py 8778
```

然後開 http://localhost:8778

`serve.py` 會送 `Cache-Control: no-store`。用 `python3 -m http.server` 的話，瀏覽器會把 ES module 存進 memory cache，改了 `src/*.js` 重新整理（甚至 hard reload）仍可能拿到舊檔，出現「明明改了卻沒生效」的假象。
