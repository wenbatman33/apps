## 1. 核心概念

你是特洛伊城的守護者。希臘聯軍圍城十年，每一關代表一年。你在城牆上佈署守軍、合成升級、施放英雄神技，撐過每一年的攻勢。

**第十關是木馬屠城**——歷史上特洛伊敗了。但這一次由你決定。

### 一句話賣點
> 「十年圍城，一手守下。合成你的守軍，改寫木馬屠城的結局。」

## 3. 核心循環

```
徵兵(花金幣) → 隨機出 Lv1 守軍 → 拖曳合成升階 → 拖上城牆塔位
      ↑                                              ↓
      └──── 擊殺敵人獲得金幣 ←──── 自動攻擊 ←────────┘
```

### 合成規則（Merge）
- 同兵種 + 同等級 兩隻拖在一起 → 升 1 階，屬性 ×1.8
- **異兵種合成**：特定組合觸發「戰術融合」，產出全新兵種（見 §5）
- 最高 Lv6；Lv6 + Lv6 → **英雄覺醒**（該兵種對應的神話人物）

### 資源
| 資源 | 取得 | 用途 |
|---|---|---|
| 金幣 💰 | 擊殺敵人、每波結算 | 徵兵、即時升級 |
| 神恩 ⚡ | 隨時間累積、完美防守加成 | 施放神技 |
| 城牆 HP ❤ | 每關重置，關間可花星星永久強化 | 歸零＝敗北 |
| 星星 ⭐ | 通關評價（1~3 星） | 解鎖英雄、天賦樹 |

### 第 10 關：木馬屠城（三階段）

**Phase 1 — 獻禮（60s）**
希臘軍撤退，海灘只留下巨大木馬。城民歡呼要求開門。
- 畫面：玩家有 60 秒「拆除倒數」，可用投石/熱油攻擊木馬
- **隱藏路線**：若在 60 秒內把木馬打到 0 HP → 直接進入「改寫歷史」真結局
- 一般情況下木馬 HP 極高（需前 9 關累積的天賦與滿級塔才打得完），多數玩家會失敗 → 進 Phase 2

**Phase 2 — 城內混戰（90s）**
木馬開啟，希臘精銳從**城內**湧出。戰場翻轉：敵人從畫面下方（城內）往上攻擊你的塔背面。
- 所有塔的射程/朝向重算，玩家必須即時重新佈署
- 城門同時被外部大軍撞擊，兩面受敵
- BGM 切換為無鼓點的高頻弦樂，畫面邊緣持續染紅

**Phase 3 — 最後一站（90s）**
普里阿摩斯宮殿前，只剩一塊 2×3 合成區。
- 每 10 秒強制失去一個塔位（宮殿逐步崩塌）
- 目標：撐滿 90 秒，讓埃涅阿斯帶著火種逃出城
- 通關 = 「特洛伊亡了，但血脈未絕」正常結局
- Phase 1 拆掉木馬 = 「十年之後，希臘人空手而歸」真結局（額外 ⭐⭐⭐ 與隱藏成就）

## 8. 華麗攻擊表現（Juice 規格）

| 事件 | 表現 |
|---|---|
| 一般擊殺 | 敵人碎裂為紅色粒子 + 金幣彈出弧線 + 白色數字跳傷 |
| 暴擊 | 時間慢動作 0.08 秒 + 螢幕輕微 zoom-in + 金色爆閃 |
| 熱油命中 | 地面留下燃燒貼圖，敵人身上掛火焰 sprite，會沿路徑蔓延 |
| 希臘火 | 火海用 shader 波動扭曲畫面，煙霧上升 |
| 英雄大招 | **全螢幕運鏡**：暗場 → 人物立繪切入 → 技能特效 → 恢復（總長 1.2s，可跳過） |
| 神諭光柱 | 天空裂開的光束 + 地面符文陣旋轉展開 |
| BOSS 出場 | 橫幅撕裂動畫 + 名字書法字 + 心跳音效 + 邊緣暗角 |
| 城牆受創 | 螢幕震動 + 灰塵落下 + 紅色邊框脈動 + 手機震動回饋 |
| 波次警告 | 頂部紅條掃過 + 「WAVE 7 INCOMING」+ 遠方鼓聲加速 |
| 連殺 | Combo 數字堆疊放大，×10 時全螢幕鍍金一閃 |

### 緊張感設計
1. **心跳音效**：城牆 HP < 30% 時持續播放心跳，隨 HP 降低而加快
2. **BGM 動態層次**：基礎層（弦樂）→ 敵人接近城牆加入鼓層 → HP 危險加入銅管尖鳴
3. **倒數壓力**：最後 15 秒數字變紅、放大、每秒一聲鐘響
4. **色調變化**：關卡進行中畫面逐漸從清晨白 → 黃昏橙 → 血紅（用 CSS filter / shader 疊色）
5. **無暫停時刻**：波次間只有 5 秒準備，且準備時間可主動跳過換取分數加成

## 9. 分數與時間

### 分數公式
```
最終分數 = (擊殺分 + 連殺加成 + 城牆完整度分 + 剩餘時間分 + 資源效率分) × 難度倍率
```

| 項目 | 計算 |
|---|---|
| 擊殺分 | 每敵人基礎分 × 等級係數（BOSS ×50） |
| 連殺加成 | Combo 每 5 層 +10%，上限 +100% |
| 城牆完整度 | 剩餘 HP% × 5000 |
| 剩餘時間分 | 每提前 1 秒 +80 分（鼓勵主動跳過準備時間） |
| 資源效率 | (擊殺數 ÷ 徵兵次數) × 300 |
| 難度倍率 | 普通 ×1.0 / 英雄 ×1.5 / 神話 ×2.2 |

### 時間機制（雙層）
- **關卡總倒數**：撐過倒數即通關（防守型計時）
- **波次倒數**：頂部細條顯示下一波何時到，玩家可點「⏩ 提前召喚」→ 立刻開下一波，獲得 **+15% 該波分數**（高手向風險決策）

### 星級評價
| 星 | 條件 |
|---|---|
| ⭐ | 通關 |
| ⭐⭐ | 城牆 HP ≥ 60% |
| ⭐⭐⭐ | 城牆 HP ≥ 90% 且 最高 Combo ≥ 30 |

## 10. 關間成長

- **天賦樹（三系）**：城防（HP/回復）、軍備（塔傷害/射速）、神恩（技能 CD/威力）

## 11. 技術規格

| 項目 | 決定 |
|---|---|
| 引擎 | Phaser 3（2D、成熟粒子系統、手機效能佳） |
| 解析度 | 1080×1920 基準，`Scale.FIT` + 安全區 |
| 音效 | Web Audio，BGM 分層混音（stem-based） |
| 存檔 | `localStorage`，含關卡進度/星星/天賦 |
| 部署 | 單頁 HTML + assets，同現有 apps 結構 |
| **DEV 微調工具** | **必做**：按 `D` 開啟，涵蓋所有 LAYOUT 變數、塔位座標、粒子參數、色彩、動畫時長；支援拖曳定位 + JSON 匯出 + PC/Mobile 切換 + 狀態強制觸發（BOSS/木馬/城破） |

### 素材產製
走 `codex exec` 內建 image_gen：
- 兵種立繪 6 階 × 5 系 = 30 張（512×512 透明背景）
- 英雄立繪 7 張（1024×1024）
- BOSS 立繪 6 張
- 背景 3 套（白天/夜戰/城內火海，1080×1920）
- UI 元件（希臘陶器紋樣風格：黑陶紅繪、赭石金）

### 美術方向
> **希臘黑繪陶器 × 現代發光特效**。基底用赭紅／炭黑／象牙白的古典配色與陶器紋飾邊框，攻擊特效則用高飽和的金橙藍發光——古老與華麗的反差就是本作的視覺記憶點。
