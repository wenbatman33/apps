# 防守特洛伊 v2 — 烈焰圍城（Troy Defense: Walls of Fire）

> 手機直向（9:16）守城塔防 · 卡通角色＋特效爆量 · 核心賣點：**戰火**
>
> 本文件為重新規劃版（v2），取代 GDD.md。定案前不動工。

---

## 0. 這次跟上一版差在哪（對 AUDIT.md 的正面回應）

上一版最大的失敗：**「守城」只是嘴上說說**——城門是背景貼圖、敵人碰到終點憑空消失、戰場是安靜的棋盤。

v2 的三條鐵律：

1. **城牆與城門是真實遊戲實體**：有血量、有裂痕階段、會被撞擊、會冒煙起火、會被轟破。玩家每一秒都看得到「城還撐不撐得住」。
2. **敵人永遠不會憑空消失**：走到城下就停下來**攻城**——撞門、架雲梯、爬牆、丟火把。每個敵人的死都有屍體、火花、粒子交代。
3. **畫面上永遠有火**：從第一關的第一秒起，畫面就至少有 3 個持續燃燒源（火把、營火、燃燒的箭塔）。戰況越激烈，火越多。「安靜的畫面」在本作是 bug。

## 1. 核心概念

你站在特洛伊城牆上往下守。希臘大軍從畫面上方的海灘登陸，一波波衝向畫面下方的城牆。你徵兵、合成、把守軍佈上城牆垛口，親手點擊釋放火油與箭雨，把敵人燒死在城下。

**第十關是木馬屠城**——歷史上特洛伊敗了，這次由你改寫。

### 一句話賣點
> 「箭如雨下，油如火瀑。十年戰火，一根拇指守下特洛伊。」

與 v1 的關鍵差異：
- **城牆從「畫面底部的一條線」變成佔 15% 高度的主角**，守軍 sprite 實際站在垛口上，看得到他們拉弓、倒油的動作。

## 3. 核心循環

```
徵兵(金幣) → 出 Lv1 守軍 → 合成升階 → 佈上城牆垛口
     ↑                                    ↓
     └── 擊殺得金幣 ← 自動攻擊 ＋ 玩家主動技能(點擊戰場)
```

### 操作原則（依你的偏好定案）
- **點擊優於拖曳**：合成改為「點第一隻 → 點第二隻同級同種」即完成；也保留拖曳。另設「⚡一鍵合成」鈕，自動合成所有可合成對。
- 上牆同理：點守軍 → 點垛口。空垛口會發光提示。
- **主動技能是點擊戰場**（不是畫線手勢）：點哪裡，火油/箭雨就落哪裡。

### 主動技能（玩家親手放火的地方 — 本作爽感核心）
| 技能 | CD | 表現 |
|---|---|---|
| 🔥 **沸油傾瀉** | 12s | 點擊城牆前任一區：油瀑從城垛傾下 → 觸地爆成扇形火海燃 6 秒，敵人著火亂竄 |
| 🏹 **萬箭齊發** | 18s | 全城牆守軍齊射：200 支箭的拋物線箭雨覆蓋點擊區，落地揚塵 |
| ☄️ **神火隕石**（神恩滿） | 神恩條 | 阿波羅降三顆火流星，全螢幕震動、白閃、蕈狀火柱 |

## 4. 城牆與城門系統（v2 的心臟）

### 城門（主目標）
- 城門 HP = 敗北條件。血條就刻在門板上（木紋裂縫式血條，不是抽象 UI 條）。
- **四段損傷外觀**：完好 → 裂痕＋掉木屑 → 破洞冒煙＋火苗 → 半塌燃燒（持續火粒子＋警報紅光）。
- 被攻城槌撞擊時：**門板凹陷形變（squash）＋ 木屑飛濺 ＋ 鐵件火花 ＋ 全螢幕震 6px ＋ 手機震動**。
- 城門被轟破 = 敗北演出：門板炸成碎片飛向鏡頭 → 敵軍剪影湧入 → 火光吞沒畫面 → 結算。**輸也要輸得壯烈。**

### 城牆垛口（塔位）
- 5 個垛口（後期關卡 7 個），守軍站上去有「就位」動畫：跳上垛口、插旗、火把亮起。
- 垛口可被**雲梯兵**攀上：爬上來的敵兵會跟守軍**在牆頭肉搏**（守軍暫停射擊改近戰），玩家可點擊該垛口觸發「推梯」把整架雲梯連人推倒——士兵慘叫墜落＋揚塵。
- 垛口被縱火兵點燃會持續掉血，需點擊滅火（3 連點）。

### 城內景深（戰損可視化）
- 城牆後方（畫面最底）畫特洛伊城剪影。城門 HP 越低，**城內火點越多**：50% 時兩處起火、25% 時半城橙紅、瀕死時全城火海＋灰燼粒子飄滿全螢幕。玩家用眼角餘光就知道戰況。

## 5. 敵方攻城體系（每種敵人 = 一種戰火演出）

| 敵人 | 行為 | 戰火表現 |
|---|---|---|
| 劍盾步兵 | 衝到城門砍門 | 每砍一下門上迸金屬火花 |
| 火把兵 | 對城門/垛口投擲火把 | 火把旋轉飛行帶焰尾，落點燃燒 |
| 盾龜陣 | 8 人舉盾方陣，頂著箭雨推進 | 箭插滿盾面、火油可從縫隙燒進去（剋制演出） |
| 雲梯兵 | 架梯爬牆 | 梯上多人攀爬，被推倒時整排墜落 |
| **攻城槌** | 蒙皮巨槌，撞門主力 | 每次撞擊全螢幕震動＋門板形變＋火花噴濺 |
| **攻城塔** | 緩慢推進的木塔，抵牆放兵 | 被火攻時逐層燃燒→整座垮塌（本作最大單體演出） |
| **投石船/投石機** | 從海灘遠程拋射**火球砸你的城牆** | 火球拖焰尾劃過全螢幕 → 命中處爆炸＋碎石＋餘燼（敵方也有火力，戰爭是雙向的） |
| BOSS（狄俄墨得斯/大埃阿斯/阿基里斯/阿伽門農/奧德修斯） | 沿用 v1 機制設計 | 出場全螢幕演出：戰旗、鼓聲、地面踏裂 |

**設計原則**：敵方也要打你、也有火光。上一版敵人只會走路，戰場像單向射擊場；v2 的戰場是**互轟**。

## 6. 戰火演出規格（本次的主章節 — 可直接照做的參數）

### 6.1 火焰系統（四層）
| 層 | 內容 | 實作 |
|---|---|---|
| 環境火 | 火把、營火、燃燒船、城內火點 | 循環 sprite 動畫＋光暈，每關常駐 ≥3 處 |
| 投射火 | 火箭、火把、火球的飛行焰尾 | 粒子 trail，20–40 粒/發，橙→紅→灰漸變 |
| 地面火 | 油池、火海、燃燒帶 | 燃燒貼圖＋向上火舌粒子，可蔓延至相鄰敵人 |
| 身上火 | 著火的敵人 | 掛火焰 sprite＋掉血＋**加速亂跑**（會點燃隊友，連鎖爽感） |

### 6.2 火花系統（Sparks — 你點名要的）
| 事件 | 火花規格 |
|---|---|
| 近戰刀劍相擊 | 6–10 粒白黃色火花，錐形噴射，重力下墜，0.3s 消失 |
| 箭中盾/石牆 | 4–6 粒火花＋箭矢彈開旋轉 |
| 攻城槌撞門 | 25 粒火花大噴發＋木屑 12 片＋塵土雲 |
| 投石落地 | 碎石 8 塊拋物線飛散＋接觸點火花環 |
| 敵人死亡 | 兵種色粒子爆裂 15 粒＋金幣弧線彈出 |
| 火球爆炸 | 白閃 1 幀 → 橙色衝擊環 → 30 粒餘燼緩降（餘燼會發光閃爍） |
| **全場常態** | 戰鬥中永遠有 5–15 粒**漂浮餘燼**橫過螢幕（風向左上），這是「戰火感」的底味 |

### 6.3 鏡頭與觸感（Juice）
| 事件 | 震屏 | 其他 |
|---|---|---|
| 一般命中 | — | 敵人白閃 1 幀＋受擊抖動 |
| 暴擊 | 2px/0.1s | 慢動作 0.08s＋金色爆字 |
| 攻城槌撞門 | 6px/0.3s | 手機震動＋門形變 |
| 火球命中城牆 | 8px/0.35s | 紅色 vignette 脈動一次 |
| 神火隕石 | 12px/0.5s | 全螢幕白閃＋音爆低頻 |
| 攻城塔倒塌 | 10px/0.6s | 塵土牆升起遮蔽半螢幕 1.5s |
| 城門瀕死（<25%） | 持續微震 1px | 心跳聲＋畫面邊緣常駐暗紅 |

### 6.4 效能預算（卡通風＋粒子爆量的前提是不掉幀）
- 全域粒子池上限 **600**（中階機實測基準），超過時優先犧牲最舊的環境粒子，**絕不犧牲玩家技能的粒子**。
- 三檔畫質自動偵測（FPS < 45 自動降檔）：高＝全開／中＝餘燼減半、無塵土雲／低＝關閉環境粒子、保留命中回饋。
- 所有火焰用 sprite sheet 動畫＋加法混合（ADD blend），不用即時 shader 模擬。

## 10. 音效（戰爭感的一半來自耳朵）

- **常駐戰場底噪**：遠方喊殺聲＋兵器碰撞環境音（音量隨敵人數量動態調整）。
- 分層 BGM：弦樂底 → 敵近城牆加戰鼓 → 城門 <30% 加銅管尖鳴＋心跳。
- 關鍵單體音：攻城槌悶響、火油澆下的「轟」、雲梯倒塌的木裂＋慘叫、城門碎裂。
- 最後 15 秒倒數鐘聲。
