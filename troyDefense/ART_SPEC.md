# 防守特洛伊 — 視覺設計規範 v2（Clash Royale 取向）

> 目的：把目前「還可以但不夠精緻」的畫面，提升到 Clash Royale 等級的質感。
> 這份文件先確認方向，確認後才動手改，避免再一次全面返工。

---

## 1. 現況診斷：為什麼現在不夠高質感

| 問題 | 現況 | 後果 |
|---|---|---|
| **格狀感太弱** | 格子是半透明白色方塊疊在沙地上，等於「一層濾鏡」 | 看起來像貼上去的 UI，不像遊戲世界的一部分 |
| **地面太單調** | 大片同色沙地、沒有紋理層次 | 空曠、廉價，佔畫面 60% 卻沒有資訊量 |
| **缺少景深** | 所有東西同一平面、沒有陰影層次與環境光 | 扁平，單位像貼紙 |
| **配色不夠有記憶點** | 沙黃＋木棕，低彩度同色系 | 灰撲撲，缺乏 CR 那種一眼識別的鮮明感 |
| **UI 是木板風** | 棕色木紋面板 | 復古但不精緻，和 Q 版單位氣質不合 |
| **單位輪廓不夠強** | 沒有描邊、輪廓光弱 | 小尺寸時糊成一團，辨識度低 |

---

## 2. Clash Royale 的視覺公式（拆解）

1. **棋盤是世界本身**：格子不是疊上去的，而是地面「本來就長這樣」——深淺交替的草皮方塊、有厚度與邊緣陰影
2. **強輪廓**：每個單位都有深色描邊 + 邊緣光，確保 60px 大小仍清楚可辨
3. **材質統一**：所有東西像上了亮漆的黏土/塑膠，柔和高光、無粗糙質感
4. **高飽和但不刺眼**：主色鮮豔，用大量中性色（石灰白、深藍）平衡
5. **UI 有實體感**：按鈕是「立體的物件」，有頂部高光、底部厚邊、按下時下沉
6. **金色是唯一的強調色**：重要數值、稀有框、勝利元素才用金

## 4. 戰場設計（最關鍵的改動）

### 4.1 格子要成為「地面本身」
現在：沙地圖片 + 半透明白方塊
改成：**地面直接畫成交替深淺的方格地磚**，每格有：
- 淺/深交替（棋盤式），讓格狀感成為場景的視覺主體
- 每格 2px 的內縮邊緣 + 1px 底部暗邊 → 產生「地磚有厚度」的錯覺
- 敵人走過的格子換成踩踏泥土色，並保留方格形狀

這一步**不需要重生地圖**，用程式繪製就能達成，而且比貼圖更銳利。

### 4.2 地圖圖片的角色改變
地圖只負責**外框裝飾**：上方海灣戰船、下方城牆城門、兩側岩石樹木。
中央區域改由程式繪製的地磚棋盤填滿 → 兩者交界用柔和陰影過渡。

**好處**：格子永遠對齊、換關卡只換外框、效能更好、視覺更銳利。

### 4.3 立體感
- 每個單位/路障底部加**橢圓柔和陰影**（現有，需加強）
- 戰場四周加**內陰影**（vignette），讓棋盤有「陷下去」的縱深
- 城牆與棋盤交界加一道陰影，強化高低差

## 5. 單位視覺規範

| 項目 | 規範 |
|---|---|
| 視角 | 略俯視 25°，看得見正面與一點頂面 |
| 比例 | 頭身比 1:2（比目前更 Q，辨識度更高） |
| 描邊 | **深色描邊 3–4px**，這是 CR 質感的關鍵，目前完全沒有 |
| 邊緣光 | 右上方向的暖色邊緣光，讓單位從背景跳出來 |
| 材質 | 上亮漆的黏土感，柔和高光、無粗糙紋理 |
| 底座 | 守軍保留小基座（區分「建築物」），敵人無底座 |
| 尺寸 | 單位佔格子的 90–110%，略微溢出格子上緣 |

### 階級視覺區分（目前只有數字徽章，太弱）
| 階級 | 增加的視覺 |
|---|---|
| Lv1–2 | 無 |
| Lv3–4 | 基座加一圈金邊 |
| Lv5 | 基座發光 + 小旗幟 |
| Lv6 | 基座發光 + 頭頂皇冠 + 持續粒子 |
| 融合 | 金色外框 + 旋轉光環 |

## 6. UI 元件規範

### 按鈕（三層結構，這是 CR 立體感的來源）
```
┌─────────────────┐  ← 頂部高光（白 30%，高度 34%）
│                 │  ← 主色面
└─────────────────┘  ← 底部厚邊（主色 darken 30%，6px）
```
按下時：整體下移 4px、厚邊縮到 2px。

### 面板
- 底：`#1E5FA8` 92% 透明度
- 描邊：`#F2EFE4` 3px
- 圓角：24px
- 頂部 30% 加一道亮藍漸層

### 字體
- 全部粗黑體，**深色描邊 4–6px**（現況已有，維持）
- 數值用金色、標題用白色、說明用淺藍白

### 生圖 prompt 的關鍵新增語句
```
- 角色有清楚的深色描邊（thick dark outline），像 Clash Royale / Brawl Stars 的單位
- 右上方向的暖色邊緣光（rim light）
- 上了亮漆的黏土質感，柔和高光
- 頭身比 1:2 的 Q 版比例
- 輪廓飽滿，縮到 60px 仍能一眼辨識
```

## 8. 實施順序（分四階段，每階段可獨立驗收）

| 階段 | 內容 | 預估 | 風險 |
|---|---|---|---|
| **A. 棋盤重做** | 程式繪製交替地磚、走道、內陰影、立體邊緣 | 30 分 | 低，純程式，不動素材 |
| **B. UI 換裝** | 配色改藍白金、按鈕三層立體、面板重繪 | 40 分 | 低 |
| **C. 素材重生** | 40 張 AI 素材（加描邊/邊緣光規範） | 20 分生圖 + 去背 | 中，需驗一張再全跑 |
| **D. 質感細節** | 階級視覺、陰影強化、粒子調整 | 30 分 | 低 |

**建議先做 A + B**：這兩階段不動素材就能看到 70% 的質感提升，而且風險最低。確認方向對了再投入 C 的生圖成本。
