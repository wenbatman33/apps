# 三國城寨人海戰重建規格

## 核心體驗

- 直式手機戰場，設計解析度 720 × 1560；敵方在上、我方在下。
- 每局 180 秒後進入加速決戰，只有攻破主城才能獲勝；主循環只有「出兵、占寨、補給、再推進」。
- 主城與已占城寨在城內持續累積駐軍；玩家用拖曳建築派出一半駐軍並決定進軍方向。
- 戰場上只保留槍盾、弓兵、騎兵三種常規兵；武將與軍師計略各自獨立。
- 重要節點與主要行軍距離上下對稱，確保雙方開局公平；不同關卡靠道路拓撲與地形改變決策。

## 24×42 格狀地圖

- 戰場固定為 24 欄 × 42 列，共 1,008 格；每格 30 × 30px，總戰場 720 × 1260px。
- 地圖程式先定義完整道路矩陣，再依矩陣鋪設 PNG 地表、道路、水面／冰面與橋面圖塊；圖像生成不得決定路線。
- 道路視覺寬三格，士兵的中心軌跡一次只能上下左右移動一格，禁止斜行、跳格或穿越非道路格。
- 戰略尋路決定下一座相鄰城寨；格狀路徑決定逐格行軍。兩者皆由同一份地圖資料提供。
- 每條道路必須通過正反向一致、連續相鄰、端點存在與主城可達的自動檢查。

## 不需要教學也能理解的操作

1. 每座建築直接顯示城內駐軍數，時間越久，數字越高。
2. 按住我方主城，拖向有道路相連的城寨，立即派出目前駐軍的一半。
3. 攻下城寨後，它變成我方顏色、留下駐軍並開始修復；修復越完整，募兵越快。
4. 每座我方城寨讓補給更快，控制越多就越容易形成兵力優勢。
5. 趙雲與火計只在下方各占一個明確按鈕，不混入隨機兵種。

## 三關規劃

### 第一關：翠谷三橋

- 道路：左、中、右三條完整格狀路線；中央路經中央城寨，左右路各經上下兩座城寨。
- 重點：學會主城拖曳、占領第一座城寨、從城寨繼續增援。
- 五座城寨：上左、上右、中央、下左、下右。
- 路線不交叉，最容易看懂，是正式玩法的基準關。

### 第二關：赤壁水峽

- 左右道路加入上下對稱的折線峽道，但不提供不存在的對角捷徑。
- 重點：側翼行軍距離增加，中央直路較快但容易正面撞軍。
- 河道四格寬，只有矩陣標記的三座石橋可以通過。

### 第三關：雪原三岔

- 左右道路使用不同於赤壁的對稱冰原折線，中央仍是完整直路。
- 四格寬冰河只有三處鋪設雪石橋，士兵不可走冰面。
- 武將進駐中央或側翼的差異最明顯，是三關中節奏最快的一關。

## 節點狀態

| 狀態 | 行為 |
| --- | --- |
| 中立 | 6 名守軍、不募兵；雙方都必須先清空守軍 |
| 我方 | 城內逐名募兵；可拖曳派出一半；提供 15% 全局補給加速；可讓趙雲進駐 |
| 敵方 | 使用完全相同的駐軍、募兵、修復與派半數規則 |
| 受損 | 換手時完整度 32%；自動修復，完整度越低募兵越慢 |

## 路線與拖曳回饋

- 可拖建築在觸碰時抬升；拖曳期間，相鄰目標會有可選提示。
- 放到合法相鄰城寨後，立即出現部隊並沿該道路前進。
- 放到非相鄰或敵方主城等非法節點時，不派兵，建築回到原位。
- 成功增援後以短提示與建築冷卻顯示結果，不開阻擋戰場的大型教學框。
- 所有合法道路都需提供符合背景彎道與橋面的多段軌跡；尋路決定「走哪幾座城寨」，軌跡決定「在畫面上怎麼走」，不得以節點間直線穿越非道路區。
- 玩家可用暫停檢查路線；暫停面板只保留「繼續」與玩法一句話。

## 建築與角色美術

- 原創三國 Q 版 3D 玩具質感，明亮、圓潤、輪廓清楚。
- 垂直戰場使用正面高角度，建築主立面朝畫面下方；禁止 45 度斜向與等角視圖。
- 主城有清楚城門、鼓與單層屋頂，份量足夠但不宮殿化。
- 小城寨是主城的精簡型：矮石牆、中央門、短屋頂、兩面小旗；中立、蜀、魏保持同一幾何輪廓。
- 普通兵顯示尺寸小於城寨，確保道路仍有行軍距離；趙雲略大一級以維持辨識度。
- UI 採深海軍藍、薄銀框、青綠我方、珊瑚紅敵方；不用厚重古董、羊皮紙或巨大裝飾框。
- 所有遊戲可視素材必須是實際 PNG／JPG／WebP 圖檔，不以程式圖形、Canvas 或 SVG 代畫。

## UI 固定層級

- 頂部：周瑜與司馬懿對峙，雙方主城生命、剩餘時間、關卡、暫停。
- 戰場：道路、城寨占領條、士兵與武將；不疊大型解說面板。
- 底部：孔明山巔指揮台、補給倍率、派兵、趙雲、火計；我方資訊固定在下方。
- 結算：勝負、原因、本局軍功、等級與升級／再戰，不遮擋必要按鈕。

## 戰鬥 UI 尺寸規格

- 戰場必須保留至少 87% 畫面高度；底部孔明指令列最多 170px，頂部軍師對峙列不得遮擋敵方主城。
- 補給資訊只有一行，高度 28px；我方與敵方資訊分列左右，不另開資訊面板。
- 行軍、趙雲、火計使用 188 × 122px 橫向小按鈕；圖示約 50px、名稱 17px、狀態 11px。
- 操作說明使用戰場內短暫 toast，2.6 秒後自動隱藏，不得常駐在指令列上方。
- 冷卻、整備與等級顯示在各自按鈕內，不增加底欄高度。

## 交付門檻

- 720 × 1560 與常見手機視窗均不得出現 UI 拉伸、左右抖動或超出畫面。
- 三關皆需實際載入、節點對齊地形並完成一場自動對局。
- 主城拖曳增援、城寨再派兵、占領補給、趙雲進駐、火計、暫停、結算、升級逐項測試。
- 程式掃描不得以動態繪圖或 SVG 產生角色、建築、背景與 UI 素材。
