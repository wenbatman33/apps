# 本輪圖像生成紀錄

生成方式：OpenAI ImageGen 內建圖像生成與圖像編輯。所有成品經洋紅去背、裁切、縮放後輸出為 PNG；遊戲內不使用 Graphics、Canvas 或 SVG 代畫素材。

## 戰場

> 原創三國 Q 版 3D 直式手機對戰競技場，敵方位於上方、我方位於下方；中央一條橫向青綠河流，只有左、中、右三座橋。上下各保留一座主寨與兩座箭塔的清楚空地，三條寬直行軍路線與橋頭爭奪區域清楚可見。乾淨、明亮、玩具模型質感，高可讀性。不要建築、角色、UI、文字或斜向透視。

## 24×42 格狀地圖 V6

V6 不再讓圖像生成決定道路形狀。圖像生成只產生可重複的方形點陣紋理；程式的 24×42 矩陣決定每一格是地表、道路、水／冰或橋面，士兵也只讀取同一矩陣行走。

### 地表與道路圖塊圖集

> 原創高品質 Q 版 3D 手機策略遊戲點陣圖塊圖集，正上方 90 度無透視視角，精確 3 欄 × 2 列六個等大方格。上排依序為翠綠草地、紅岩緊實土壤、潔白雪地；下排依序為黃褐夯土路面、淡色砂岩路面、掃雪後的淺褐路面。每格材質鋪滿邊緣且四邊可無縫重複，格間只留純 #ff00ff 分隔線。只要均勻材質，不要道路造型、轉角、物件、建築、角色、UI、文字、符號、透視或方向性陰影；道路形狀由遊戲格子矩陣決定。

### 水面、冰面與橋面圖塊圖集

> 原創高品質 Q 版 3D 手機策略遊戲障礙與橋面圖塊圖集，正上方 90 度無透視視角，精確 3 欄 × 2 列六個等大方格。上排依序為清澈青綠河水、紅岩峽谷深藍水面、淺藍裂紋冰面；下排依序為木橋橋面、淡砂岩橋面、覆雪石橋橋面。每格鋪滿邊緣，水與冰四邊可無縫重複；橋面垂直連接上下邊緣。格間只留純 #ff00ff 分隔線。不要建築、角色、UI、文字、符號、斜橋、曲線道路、透視或浮水印；橋梁位置由遊戲格子矩陣決定。
