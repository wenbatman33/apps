# 三國爭鋒｜完整 App 與視覺重建規劃

## 0. 本輪決策

- 先停止擴充戰鬥功能，先鎖定完整 App 流程、視覺語言與出兵操作。
- 參考圖只取「製作品質、色彩、景深、資訊清楚度」，不複製既有遊戲角色、Logo、建築或 UI。
- 美術定位：**三國戰爭 × Q 版 3D × 立體桌上沙盤 × 現代手機遊戲 UI**。
- 遊戲說明目前只建立入口和空白頁面狀態，不撰寫內容。
- 第一批只製作三張方向稿：首頁、天下地圖、實戰畫面。方向確認後才拆成正式素材。

## 1. 一句話產品體驗

玩家從天下地圖選擇戰役，以主城累積的駐軍搶占道路上的城寨，從已占城寨繼續派兵擴張；武將負責突破，軍師負責封路，最後攻破敵方主城。

## 2. 完整 App 流程

```text
啟動畫面
  ↓
首頁
  ├─ 出征 → 天下地圖 → 關卡資訊 → 戰前配置 → 戰鬥
  │                                      ↓
  │                         勝利／戰敗 → 武將成長 → 天下地圖
  ├─ 武將 → 武將列表 → 武將詳細／升級
  ├─ 設定 → 音效／音樂／畫質
  └─ 遊戲說明 → 僅保留空白入口，內容待玩法確定
```

### 2.1 啟動畫面

- 1.2–1.8 秒，黑底轉入戰火天空與軍旗。
- 僅顯示遊戲標誌，不顯示按鈕或長文。
- 素材：啟動背景、遊戲標誌、短促火星序列幀。

### 2.2 首頁

- 中央主視覺：大型 Q 版武將帶領成群士兵衝向遠方城寨。
- 上方 22% 保留標誌；下方只放三項：`出征`、`武將`、`設定`。
- `出征`是唯一高強度主按鈕；另外兩項縮小為次要入口。
- `遊戲說明`使用右上角小入口，現在點入只顯示「內容準備中」。
- 首頁不可出現戰鬥數值、兵卡或複雜資源列。

### 2.3 天下地圖／選擇關卡

- 使用可上下捲動的立體中國沙盤，不用卡片列表。
- 河流是主要視覺導引；道路串接關卡城寨，未解鎖關卡顯示關門狀態。
- 點關卡後只從下方升起一張小型戰報：地名、地形、敵將、主要機制、`出征`。
- 已完成關卡直接顯示戰旗與最佳戰績，不使用滿屏星星。

### 2.4 戰前配置

- 只確認三件事：本關地圖縮圖、出戰武將、軍師計略。
- 常規兵種仍由每次派兵隨機決定，不在此頁組牌。
- 主按鈕只有 `開戰`；返回動作固定在左上角。

### 2.5 戰鬥

- 頂部 7%：敵我軍師肖像、主城耐久、倒數、暫停。
- 中間 80%：完整戰場，不放教學面板、不用巨大提示框。
- 底部 13%：三個軍令——派兵、巨將、拒馬；孔明只作為小型指揮角色，不佔中央。
- 戰場必須有明確戰線、兵群、軍旗、塵土和攻城反應，整體感受是戰爭，不是數字表格。

### 2.6 暫停

- 背景降低亮度但保留戰局可讀性。
- 只有 `繼續`、`重新開始`、`返回天下` 三項。
- 暫停時可觀察道路，不可偷偷繼續募兵、移動、冷卻或攻擊。

### 2.7 結算與成長

- 先表現敵方主城陷落或我方撤退，再出現結算卡。
- 顯示勝負、軍功、趙雲經驗、可升級狀態和下一步。
- 勝利 +3 軍功，戰敗 +1；戰敗仍能成長。
- 主按鈕：勝利時 `下一關`，戰敗時 `再次出征`；另有小型 `返回天下`。

## 3. 出兵操作：不看說明也能懂

### 3.1 唯一主要操作

1. 我方城池持續顯示駐軍數，例如 `24`。
2. 按住我方城池後，只有相鄰合法道路發亮，其他道路保持原狀。
3. 拖向相鄰城池時，路上即時顯示 `12` 人的半數兵團預覽，來源顯示 `24 → 12`。
4. 放開後立即派出 12 人，來源城內保留 12 人。
5. 部隊以一個清楚的方陣出發；同一批兵共用目標和行軍路線，不顯示散亂單兵。

### 3.2 操作回饋

- 合法目標：城寨底座放大 6%、旗幟亮起、道路出現陣營色流向。
- 非法目標：不顯示箭頭；放開後建築回彈，不出兵。
- 兵力不足：駐軍數短促震動一次，顯示 `至少需要 2`，不彈視窗。
- 派兵成功：一面小軍旗先落在路口，兵團從城門衝出。
- 另保留無障礙備援：點來源一次，再點高亮目標也可派兵。

### 3.3 隨機兵種

- 每次派兵只隨機一種編制：槍盾方陣、弓兵隊或騎兵隊。
- 出發前 0.35 秒由城門旗幟／兵種剪影預告，不使用隨機卡牌。
- 數值仍是一名一名結算，但畫面以 4–6 人兵群呈現，減少雜亂和抖動。

### 3.4 武將

- 點 `巨將`，再點我方城寨：趙雲由主城沿真實道路前往。
- 行軍時為普通士兵約 2.5 倍，成為清楚的突破焦點。
- 首次接敵發動衝鋒；進駐後縮小到城寨側面，不遮住駐軍數。

### 3.5 軍師拒馬

- 點 `拒馬` 後，只有可布陣的道路段發亮，而不是要求猜測點哪座城。
- 點道路段後落下拒馬陣，阻擋來軍 5.5 秒；受阻兵團在拒馬前重新列陣。
- 計略與派兵、隨機兵種完全分開，按鈕內直接顯示冷卻倒數。

### 3.6 敵軍可讀性

- 開戰 1.5–2.5 秒內，敵方主城一定有第一批紅軍出陣。
- 敵軍下令前，目標道路先出現 0.45 秒紅色流向，再由城門出兵。
- 敵方城寨各自能出兵、增援或進攻；城內兵力滿載時不得停留不動。
- 玩家能從紅色流向、兵團方向和城寨數字理解敌军行为，不靠隐藏规则。

## 4. 統一視覺語言

### 4.1 關鍵詞

`戰爭張力`、`Q 版 3D`、`大型兵群`、`立體中國地貌`、`簡單城寨`、`清楚道路`、`現代 UI`。

### 4.2 色彩角色

- 我方：翡翠綠、青玉色、暖金，只用於領地、道路流向和可操作狀態。
- 敵方：漆紅、珊瑚紅、暗金，只用於敵領與警示。
- 中立：砂岩、灰米色、低飽和黃旗。
- UI 基底：深海軍藍／近黑藍；邊框只用薄金屬邊，不使用厚白框、羊皮紙或木雕面板。
- 戰場：自然色保持飽和但不螢光，火光與塵土提供戰爭氛圍。

### 4.3 造型尺度

- 主城：戰場寬度 15–18%，簡單厚實、有清楚城門，不做宮殿。
- 小城寨：主城約 58–64%，同一幾何骨架換陣營色。
- 普通兵：城寨高度 22–26%，以群組排列。
- 武將：普通兵 2.5 倍，輪廓必須在縮圖仍可辨識。
- 道路：視覺寬度至少可容納兩列兵團；任何地方不得縮成單兵細線。

### 4.4 鏡頭規則

- 戰鬥建築固定正面高角度，門朝畫面下方，不使用 45 度等角斜城。
- 天下地圖可用更高的立體沙盤視角，強調山川景深。
- 首頁可使用電影式低角度角色，但遠方城寨仍保持簡單清楚。

### 4.5 UI 規則

- 所有底板、按鈕、徽章均使用實際 PNG；不以 Graphics、Canvas 或 SVG 代畫。
- 圖片保持原始比例；需要彈性寬度時，拆成左右端帽與可延伸中央紋理，禁止直接非等比拉伸。
- 一個畫面只有一個主要按鈕；戰鬥畫面例外，只保留三個並列軍令。
- 文字直接排版，不把長文烤進背景圖；字級與對比以 360px 寬手機仍可讀為準。

## 6. 首批視覺資產清單

### A. 方向確認稿

1. 首頁主視覺：9:16，無 Logo、無按鈕文字，保留上下安全區。
2. 天下地圖：9:16，五種地形區、河流主軸、清楚關卡道路。
3. 戰鬥完整畫面：9:16，展示上下戰線、寬道路、兵團、拖曳半數與小型 HUD。

### B. 方向核准後才正式製作

- 首頁背景與前景角色分層 PNG。
- 遊戲標誌與章節標題圖。
- 天下地圖底圖、關卡節點、鎖定城門、完成戰旗。
- 五章地形圖塊圖集與環境裝飾圖集。
- 三陣營主城／城寨的完整、受損、陷落狀態。
- 槍盾、弓兵、騎兵與趙雲的統一格數動畫表。
- 首頁、選關、戰前、戰鬥、暫停、結算共用 UI 圖集。
- 軍師計略圖示與拒馬／火計序列幀。

## 7. 製作順序與停止線

1. 先審三張方向稿：只判斷是否有戰爭感、是否夠精美、角色與建築比例是否正確。
2. 核准後製作首頁與天下地圖的可操作流程。
3. 完成戰前配置、暫停和結算頁。
4. 再依已核准的戰鬥方向重做第一關，完成出兵與敵軍可讀性測試。
5. 第一關通過後，才擴展其他 19 關及批量素材。

在方向稿未核准前，不再批量生成城寨、地形、角色或 UI，避免繼續浪費時間。

## 8. 驗收標準

- 從首頁最多兩次主要點擊即可進入戰鬥。
- 初次玩家不讀說明，五秒內能看懂「從我方城池拖到相鄰城池」。
- 拖曳過程一定看得到合法道路、半數預覽、來源剩餘與目標。
- 開戰 2.5 秒內可看見敵方第一批兵團離城。
- 戰場上的部隊以兵團呈現，道路可容納至少兩列，不出現單兵細線與左右抖動。
- 360×780、390×844、430×932 三種直式尺寸無 UI 重疊、切邊、拉伸或空白浪費。
- 頂部不超過 7%，底部不超過 13%，戰場保留至少 80%。
- 首頁、天下地圖、選關、戰前、戰鬥、結算看起來屬於同一款遊戲。
- 所有可視素材皆為正式 PNG／JPG／WebP，禁止程式繪圖與 SVG 假素材。
