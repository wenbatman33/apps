WIDGET DEMO

🏀 球員投籃浮層

這是一個普通的 HTML 內容頁面。籃球員、籃框、計分都是用 basketball-player-widget.js 掛上去的浮層。你可以一邊讀文字，一邊按住畫面投籃。

怎麼玩

操作

  • 📱 按住畫面任意處開始蓄力
  • ⚡ 蓄力條會出現在畫面下方
  • 🏀 放開就會投籃
  • 🎯 蓄力大約 65% 時最準
  • 👕 右上角可切換 尼克 / 馬刺 隊球員

怎麼用在自己的頁面

把這兩行加到任何 HTML 頁面的 <body> 結尾就好：

<script src="basketball-player-widget.js"
        data-assets="assets/players"
        data-team="knicks"></script>

需要的素材結構：

assets/players/
  ├─ knicks_ready.png   ← 準備姿勢
  ├─ knicks_shoot.png   ← 投籃出手
  ├─ spurs_ready.png
  └─ spurs_shoot.png

關於人物素材

AI 生成（NBA 2K 風格）

球員人物用 OpenAI image_gen 透過 codex exec 產生。 生圖腳本與 prompt manifest 都放在 scripts/ 下，可以隨時改 prompt 重跑：

node scripts/gen_via_codex.mjs

為什麼分成 widget

跟 basketball-widget.js 一樣的設計：一行 script tag 就能把投籃小遊戲掛到任何頁面上， 不會搶走原本內容的位置（HUD 跟提示是 position: fixed，球員浮在角落）。 未來想換素材、換隊伍、換籃框位置，都只動 widget 內部。
