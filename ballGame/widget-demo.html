🏀 Basketball Widget 示範

這頁是一個完全普通的網頁，沒有任何特別 markup，只在最後加了一行：

<script src="basketball-widget.js"></script>

瞄準器自動出現在右下角，籃框出現在左下角，HUD 在左上角。點籃球或按空白鍵就出手。

把 basketball-widget.js 丟到任何網站，加這行 script 就能玩。

整合方式

  1. 把 basketball-widget.js 放到你的網站
  2. 在任何頁面的 <body> 結尾前加一行 script
  3. 就這樣

不需要 jQuery、不需要 React、不會跟你的 CSS 衝突（class 都用 bbw- 前綴 + 超高 z-index）。
