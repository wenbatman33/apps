# 🦝 浣熊推幣機 RACCOIN

Three.js + cannon-es 的 3D 推幣機 Roguelike。PC（滑鼠）與手機直屏（點擊）皆可玩。

## 玩法

- 滑鼠移動瞄準、左鍵（或點擊機台）投幣；推板前後移動，把硬幣推落前緣得分
- 每回合達成目標分數 → 進商店構築 → 完成 15 回合獲勝，可續戰無盡模式
- 硬幣自動回充（預設每 2.5 秒 +1，上限 60），也可用 🎟️ 票券兌換
- 連續得分累積 Combo 與輪盤能量，連擊結束時觸發幸運輪盤

## 操作

| 操作 | 按鍵 |
|---|---|
| 瞄準 / 投幣 | 滑鼠移動 / 左鍵（手機：點擊） |
| 選特殊硬幣 | 數字鍵 1〜9 或點擊硬幣夾 |
| 取消選擇 | 右鍵 / Esc |
| 使用道具 | Q / W / E / R |
| 加速 | Space（按住）或 ⏩ 鈕 |
| 暫停 | Esc / ⏸ |
| DEV 微調工具 | D 或右下 ⚙ |

## 內容（MVP）

- 硬幣：銅/銀/金 + 17 種特殊幣（票券、黏著、炸彈、巨大、磁鐵、複製、加倍、兔子、狼、肥料、種子、水滴、雷射、回歸、龍捲風、清除、核爆）+ 5 種負面幣（鏽蝕、石頭、小偷、詛咒、稅務）
- 8 種晶片（被動）、6 種主動道具、8 種輪盤獎勵、3 階難度、無盡模式
- 商店：特殊硬幣 / 晶片 / 獎品 / 擴充硬幣夾 / 重抽
- 角色：浣熊店長（經濟型；之後可擴充規格書中其他角色）

## DEV 微調工具

按 `D` 開啟：相機（PC/手機分開）、機台尺寸與推板參數、物理（重力/摩擦/阻尼）、
遊戲數值（Combo、轉換率、回充、輪盤門檻）、狀態觸發（強制輪盤/跳回合/生成任意硬幣）、
HUD 拖曳定位，以及 💾 匯出 LAYOUT JSON（同時寫入剪貼簿與 localStorage）。

## 本地執行

```bash
python3 -m http.server 8642
```

開 http://localhost:8642 （需要網路載入 three.js / cannon-es CDN）。

## 與規格書的刻意差異（v1）

- 掉下機台（含側邊）**一律計分**：實測側溝「白掉」挫折感太重，先移除；要硬核可再開
- 手持硬幣自動回充：確保永遠玩得下去（失敗僅在極端資源枯竭時觸發）
- 鍍層系統、多角色、存檔續玩、Seed 商店尚未實作（規格書 §10/§15 後續擴充）
