# Brick Blast

彈射式打磚塊，200 關，PC 與手機共用同一份程式。純瀏覽器直跑的 ESM 專案，**不需要任何建置流程**。

## 玩法

- 從底部發射點瞄準，放開後一整排小球依序射出
- 小球撞到磚塊扣 1 血，血量歸零即消失
- 所有球回收後，磚塊整體下移一行並補上新的一行
- 磚塊碰到底部紅線即失敗；波次用盡且清光所有磚塊即過關

磚塊顏色直接反映血量，分群對應：

| 血量 | ≤40 | 42~72 | 90~150 | 200~350 | 350+ |
|---|---|---|---|---|---|
| 顏色 | 藍 | 綠 | 橘 | 紅 | 紫 |

同一群數字同一個顏色，一眼就能分辨哪塊難打。磚塊是四邊帶斜角的立體方塊，光源固定從左上打（三角磚四種朝向各有自己的貼圖，不是旋轉同一張，否則光會跟著轉）。

### 格子種類

| 外觀 | 名稱 | 說明 |
|---|---|---|
| 實心方塊（直角） | 一般磚 | 數字為血量，撞一次扣 1 |
| 實心三角形 | 三角磚 | 斜面 45 度反彈，可把直球折成橫向，四種朝向 |
| 空心綠圈 `+1` | 加球 | 碰到多一顆球，不反彈 |
| 空心黃圈（雙向箭頭） | 雷射 | 碰到後清掉所在的整行與整列 |
| 空心紫圈 `×3` | 倍增 | 本回合球數變三倍，回合結束後歸還 |

道具一律是**空心圓**、磚塊一律是**實心方塊或三角形**，兩者一眼可分。

## 分數與紀錄

過關結算會給分：

```
分數 = (破壞磚塊 × 20 + 命中次數 × 2 + 拾取道具 × 60) × (1 + 關卡 × 0.05)
       + 過關獎勵 1000 + 剩餘效率 × 250
```

每一關獨立保存三項個人最佳（各自取最好，不必同一場達成）：

- **最高分**
- **最少回合**
- **最少用球數**

刷新任一項時，結算畫面該列會標上 `NEW`。主選單的**排行榜**可依 `分數` / `最少球` / `最少回合` / `關卡` 四種方式排序，並顯示總分、通關數與總星數。紀錄存在 localStorage，換裝置不會同步。

## 操作

| 操作 | PC | 手機 |
|---|---|---|
| 瞄準 | 滑鼠按住拖曳，或 `←` `→` 微調 | 手指按住拖曳 |
| 發射 | 放開滑鼠，或 `空白鍵` | 放開手指 |
| 取消瞄準 | 指標移到發射點下方 | 同左 |
| 加速 | 左下 `»` 鈕 | 同左 |
| 收球 | 右下「收球」鈕，或 `R` 鍵 | 右下「收球」鈕 |

瞄準時會畫出**預測線**：連續實線、能穿過多段反彈，撞擊點有亮點標記，會被打到的磚塊亮起金框。

回合超過 9 秒會自動加速，超過 14 秒開始把球導回底部，回合一定收得回來。球速刻意放慢到看得清彈跳過程，趕時間就按加速鈕。

## 執行

```bash
python3 -m http.server 5183
```

然後開 http://localhost:5183 。也可用 VS Code Live Server 之類的任何靜態伺服器。

## DEV 微調工具

按 `D` 鍵或點右上角齒輪開啟，可即時調整：

- **LAYOUT**：遊戲場位置、死亡線、發射點、HUD 各元素座標與字級、按鈕位置
- **RULES**：球半徑、球速、連射間隔、加速門檻
- **狀態測試**：加球、清空盤面、直接過關／失敗、跳關、解鎖全部、500 球壓力測試
- **PC / Mobile** 兩套版面可分別調整
- 調完按「💾 匯出目前版面」得到 JSON，貼回 `src/config.js` 的 `LAYOUT_PC` / `LAYOUT_MOBILE` / `RULES`

## 盤面設計

- **磚少而厚**：第 1 關就給 41 顆球、21 塊磚、血量 5~55。盤面前期稀疏、後期漸密，單塊磚要打好幾回合才破
- **每塊磚血量各自浮動**：同一波裡多數好打、少數特別厚，所以盤面顏色是混雜的，不是整片同色
- **總血量正規化**：每關的初始盤面與每一波新行，總血量都被壓到一個隨關卡單調遞增的目標值。這讓「有難有易」和「難度可控」同時成立
- **縱向通道**：每關固定 1~2 條欄位大多留空並在兩側築牆，球斜射進去能在夾道間連續彈擊。道具會避開通道欄，不會全擠在一起
- **反射微擾動**（±0.86°）：少了它，同角度射出的球會走完全一樣的路徑，整排球看起來就是一條線

## 自動測試

### 健壯性

```bash
node tools/simtest.mjs
```

無頭模擬（不需瀏覽器），用彈道模擬 AI 實際玩過每一關，檢查是否可通關、有無球體卡死（單回合超過 90 秒）、有無穿透（球飛出場外）。

指定關卡：`node tools/simtest.mjs 1 50 100 200`，全跑：`node tools/simtest.mjs $(seq 1 200)`。

### 難度曲線

```bash
TRIALS=3 node tools/balance.mjs
```

每關跑多次帶擾動的模擬（模擬真人不會每球都打在最佳角），輸出：

- **通關能力**：哪幾關完全過不了（必須為零）、哪幾關需要重試
- **難度曲線**：以「超額回合數」（通關回合 − 波次）為指標
- **難度倒掛檢查**：找出比後續關卡明顯更難的關卡
- **分段平均**：每 40 關一段，檢查是否逐段遞增
- **彈跳感**：每球平均撞擊次數

目前狀態：

```
可通關：200/200   每關至少能過（必須 100%）✓
一次過：168/200   32 關需要重試，代表有挑戰性
難度倒掛：無      沒有關卡明顯比後續關卡更難 ✓
分段平均：3.95 → 4.26 → 4.79 → 5.18 → 5.67  逐段遞增 ✓
```

報告區分兩個指標：**可通關**必須是 100%（不能有玩家過不了的關），**一次過**則是越低越有挑戰。

## 結構

```
index.html            進入點
styles.css            外框樣式（遊戲本身全部由 PixiJS 繪製）
vendor/pixi.min.mjs   PixiJS v8.6.6
src/
  config.js           版面、玩法數值、主題色
  core/
    physics.js        圓 vs 矩形碰撞與反射
    level.js          200 關程序生成（以關卡編號為 seed，可重現）
    game.js           回合狀態機，與渲染完全解耦
  view/
    textures.js       所有貼圖以 Canvas 2D 程式生成，零美術素材
    renderer.js       場景繪製
    fx.js             粒子與震屏
    hud.js / menu.js / ui.js
  input/aim.js        滑鼠與觸控共用的瞄準輸入
  audio/sfx.js        WebAudio 即時合成音效，零音檔（正弦木琴音色，撞擊為固定單一音高）
  store/save.js       localStorage 進度與星等
  dev/devtools.js     DEV 微調工具
tools/
  simtest.mjs         無頭模擬測試
  ai.mjs              彈道模擬 AI（供測試選角度）
```

關卡不存檔案：`makeLevel(n)` 以關卡編號當 seed 生成，同一關每次都長一樣。
