# 房產大亨

原創手機直屏房產棋盤小遊戲。一局約 5–10 分鐘，四位玩家在 32 格中國風棋盤爭奪 8 組、共 24 座城市；每組固定相鄰 3 城，包含買地、三棟住宅、中國地標、租金、同區三城 ×2、資產價值兩倍強買、環遊薪資，以及機會命運牌與全場趣味事件。

## 啟動

本專案**沒有建置步驟**：`src/*.js` 是瀏覽器直接執行的 ES module，改完存檔重整瀏覽器即可。
因為原生 ES module 受同源政策限制，需透過本機靜態伺服器開啟（不能用 `file://` 直開）：

```bash
python3 -m http.server 5174
```

然後開 <http://localhost:5174>。規則單元測試：

```bash
npm test
```

## 目錄結構

- `index.html` — 唯一入口，直接載入 `./src/main.js`
- `src/` — 遊戲原始碼（原生 ES module，無需編譯）
- `vendor/` — 第三方函式庫的 ESM 版本，以相對路徑 import，不依賴 npm 或 CDN
  - `phaser.js` / `phaser.esm.min.js`、`three.js` / `three.module.min.js` / `three.core.min.js`、`cannon-es.js`、`RoundedBoxGeometry.js`
- `assets/` — 遊戲實際載入的圖與音效
- `tests/` — `node --test` 規則測試

要移植到其他平台，整包複製 `index.html` + `src/` + `vendor/` + `assets/` 即可，不需 npm install、不需打包。

## 完整流程

1. 首頁：進入遊戲或查看規則。
2. 角色：從 8 位喜劇風 Q 版人物中選擇棋子（單人模式，你操作 1 位，其餘 3 位由 AI 接手）。
3. 入場：顯示四位參賽角色與快節奏玩法提示。
4. 對局：真實 3D 雙骰、一次性精準骰子券、移動、環遊薪資、購地、建屋、升級、收租、兩倍強買、同區加乘。
5. 趣味事件：機會卡、命運卡、高鐵選站、世界巡遊賽、監獄脫困與命運輪盤都有實際可執行效果。
6. 破產：無法支付費用時播放專屬破產畫面、土地回歸銀行並淘汰該玩家。
7. 結算：限時結束或剩最後一位玩家時，顯示四人總資產排名，可再戰或回首頁。

## 規則

- 四位玩家每回合依序擲一次雙骰。
- 首次購買空地時只有土地，不會自動出現房子。
- 之後每次落在自己的地，依序建第 1、2、3 棟住宅。
- 土地已有 3 棟住宅後，下一次再落在該地才能升級；8 個系列各有對應的中國知名地標。
- 落在對手的地先支付租金，之後可用該資產價值的兩倍強制收購。
- 棋盤有 8 種系列色，每個系列固定相鄰 3 座城市；集齊同色三城後，該區所有租金 ×2。
- 棋盤平時只顯示城市與區域名稱；角色停到空地時，購買面板才顯示土地價格。
- 每次完整繞過起點立即領取 $180 薪資。
- 平常回合只使用正常 3D 物理骰子；踩到骰子工坊或抽中「精準骰子券」機會卡，才會取得 1 次控制機會。
- 使用控制券時，蓄力指針可鎖定 2–5、5–8 或 8–12 點，並可指定單數或雙數；選擇普通擲骰則保留道具。
- 機會與命運卡會造成移動、資金、免費建設、免租、骰子控制、租金加倍或全場財富變化；卡片由玩家看完並確認後才關閉。
- 高鐵可直接選擇策略城市；監獄需擲出雙數、支付保釋金或停留一次。
- 落在命運輪盤格時，獨立圓盤會在固定指針下實際旋轉，停止角度決定全場效果；世界巡遊賽則依旅遊分數發放獎金。
- 限時結束後以現金＋房地產價值結算；現金低於 0 的玩家破產淘汰。

## 技術與素材政策

- Three.js：整座 32 格棋盤、等比例 3D 格子、區域色帶、房屋、地標、角色棋子、45 度跟隨鏡頭與傳送光束均為即時 3D 場景。
- Three.js + cannon-es：真正的 3D 骰子模型、重力、碰撞、反彈與角速度；依實際朝上面取得點數。
- Phaser 3（原生 ESM）：以高解析度遊戲引擎文字及點陣 UI 負責 HUD、對話框與互動，不使用 DOM 排版遊戲介面。
- ImageGen PNG：首頁、3D 場景下方的高畫質中國園林地表、8 人角色圖集、機會命運卡、特殊事件、破產與冠軍畫面等點陣素材；棋盤格與建築本身不是底圖的一部分。
- 未使用 Phaser Graphics、Canvas 產圖或 SVG 遊戲素材。

ImageGen prompt 摘要與後製方式記錄在 `assets/ASSET_MANIFEST.md`。
