# Western Bar — 玩法規格 v3（依 Casio CG-300 官方手冊）

> **取代** v1 (`western_bar_dev_spec.md`) 與本檔先前的 v2 內容。
> 主要依據：1984 Casio CG-300 Western Bar 原廠說明文件 + YouTube 影片觀察。

---

## 1. 核心架構

- **10 個 Level × 3 個 Pattern** = 共 30 小關
- 玩家為「醉酒警長」，在底部走道**左右移動 4 欄**，按 **FIRE 朝上開槍**
- 3 次失誤 = GAME OVER

---

## 2. Pattern 1 — 吧台射擊（主要玩法）

### 場景
```
       [上層] 服務生站位（左/中/右），會丟酒器；憤怒顧客丟雜物
        │       │       │       │
        ▼       ▼       ▼       ▼     ← 物品從上方下落
       Col 0   Col 1   Col 2   Col 3
       ─────────────────────────────
       [下層] 玩家走道（4 欄）        ← 玩家左右走 + 朝上開槍
       SCORE 00000   ♥♥♥   HITS 0/20
```

### 操作
- **← / A**：左移一欄
- **→ / D**：右移一欄
- **Space / F / FIRE**：朝上開槍

### 物品類型
| 類型 | 出現方 | 行為 | 分數 |
|---|---|---|---|
| **杯子** Cup | 服務生 | 緩慢下落，可擊碎得分 | 10 |
| **酒瓶** Bottle | 服務生 | 中速下落，可擊碎 | 20 |
| **盤子** Plate | 服務生 | 較快下落，可擊碎 | 30 |
| **蘋果** Apple | 憤怒顧客 | 下落，**擊中玩家就失誤** | — |
| **煙灰缸** Ashtray | 憤怒顧客 | 下落，**擊中玩家就失誤** | — |
| **炸藥** Dynamite | Pattern 3 才出現 | 不能射、不能爆腳邊 | — |
| **特殊酒瓶** Bonus | 一石三鳥觸發掉落 | 擊碎得高額 bonus | 200 |

### 重疊堆疊加分機制 ★（本作核心 hook）

當玩家按 FIRE，子彈從玩家所在欄向上飛，會**穿過**該欄上所有可破壞物品。一發子彈擊中 N 個物品時，分數倍率：

| 一發擊中數 | 倍率 | 額外效果 |
|---|---|---|
| 1 個 | ×1.0 | — |
| 2 個 | ×1.5 | combo +1 |
| 3 個 | ×2.5 | **一石三鳥**：天上掉特殊酒瓶 |
| 4+ 個 | ×4.0 | 一石三鳥 + 連擊累積 |

### 過關條件
- **擊碎 20 個物品** → 進入 Pattern 2

### 失誤條件
- 蘋果 / 煙灰缸落到玩家所在欄底
- 漏接酒器**不**算失誤（只是分數累積慢）
- 射中炸藥（Pattern 3）

---

## 3. Pattern 2 — 生死決鬥

### 場景
- 警長躲在桌後（自動進入掩體狀態）
- 惡棍（Desperado）會閃現於酒吧角落（左 / 右），跳出來開槍
- BGM 切換 + 馬刺叮噹音 + 木門吱嘎音

### 玩法
- 惡棍出現於角落 → **蓄勢** → 開槍
- 玩家要在惡棍開槍前按 **FIRE** 擊中惡棍
- 玩家需朝惡棍出現的方向開槍（FIRE 會自動朝惡棍方向）

### 勝負
- **玩家先擊中 3 次** → 勝利、警長跳勝利舞、晉級下一 Level
- **桌子被打 3 次 → 掩體碎裂**，玩家暴露；再被擊中即失誤
- 桌子破後若仍未擊倒惡棍 3 次，下一發中彈直接 game over（或失誤一次）

---

## 4. Pattern 3 — 炸藥危機

從特定 Level（建議 L3 起）才會出現。

### 機制
- 場上會出現**燃燒的炸藥**（從上方落下或被服務生丟到腳邊）
- **絕對不能射炸藥** → 射中 = 失誤
- 炸藥落到玩家腳邊 → 引信點燃倒數
- 倒數歸零 → **爆炸 = 失誤**

### 解法
- 玩家要連續快速狂按 **RIGHT** 鍵
- 每按一次 = 倒一滴威士忌澆熄引信
- 引信歸零前澆熄完成 = 安全；否則爆炸失誤

### 高難度（L7+）
- 服務生會**直接把炸藥丟到玩家腳邊**（不從上方落下）
- 解法相同（狂按 RIGHT）

---

## 5. 失誤與 GAME OVER

**3 次失誤即結束。** 失誤觸發：

1. ✅ 被顧客雜物（蘋果 / 煙灰缸）落地擊中
2. ✅ Pattern 2 決鬥被惡棍子彈擊中（且桌子已碎）
3. ✅ Pattern 3 射中炸藥
4. ✅ Pattern 3 炸藥在腳邊爆炸

## 7. 控制（PC / Mobile）

| 操作 | PC | Mobile |
|---|---|---|
| 左移 | ← / A | 左下虛擬鍵 |
| 右移 | → / D | 右下虛擬鍵（澆酒時連點此鍵） |
| 開槍 | Space / F | FIRE 大按鈕 |

## 8. 開發優先順序

1. **Pattern 1 核心**（物品下落、重疊射擊、一石三鳥、失誤計算）
2. **Pattern 2 對決**（惡棍跳出、桌子掩體、計次）
3. **Level 推進**（20 hit → P2 → P1 加難度 → P2 → …）
4. **Pattern 3 炸藥**（可延後）
5. **美術整合 + Mobile**
