## 1. 遊戲概述

玩家扮演一名西部酒吧的警長,固定在畫面下方的走道(2 格)左右移動。遊戲分兩種交替出現的情境:

- **射擊閃避**:擊落酒保拋出的酒器來得分,同時閃避客人丟來的攻擊物。
- **強盜對決**:躲在桌子後與闖入的強盜互射,搶在掩體被打爛前擊倒對方。

兩種情境循環推進,難度逐關上升,直到生命耗盡。美術走手繪卡通風,角色與場景皆為彩色手繪。

## 2. 核心玩法迴圈

```
開機演出
   │
   ▼
┌─────────────────────────────────┐
│  關卡開始                         │
│  ├─ 階段 A:射擊閃避(基礎密度)    │
│  ├─ 階段 B:射擊閃避(加重)        │
│  └─ 階段 C:射擊閃避 + 強盜對決    │
└─────────────────────────────────┘
   │  達成過關條件
   ▼
下一關(難度提升)── 每 3 關進入下一等級
   │
   ▼
生命耗盡 ──► GAME OVER ──► 結算 / 最高分
```

每一關由 3 個階段(pattern)組成,三個階段全部完成才算過關;第 3 階段固定包含強盜對決作為關底考驗。

## 4. 得分機制

**得分來源**

1. **擊落酒器**——酒保拋出的杯/瓶/碟,命中即得分。三種酒器分值不同(見參數總表),鼓勵玩家優先處理高分目標。
2. **連續命中加成**——連續命中不漏接可累積連擊數,每達 5 連觸發一次倍率加成;被攻擊物擊中或漏接酒器則連擊歸零。
3. **擊倒強盜獎勵**——對決階段成功擊倒強盜,給予固定獎勵分。

**不得分項目**

- 閃避攻擊物本身不給分,它屬於防守行為。
- 漏接酒器不扣分,但會中斷連擊。

**顯示規則**

- HUD 即時更新當前分數。
- 整局結束時與歷史最高分比對,刷新則更新並持久化保存。

## 5. 生命 / 失誤判定機制

生命以「失誤標記」呈現,採事件觸發制,非連續血量。

**會記一次失誤的情況**

| 情境 | 觸發條件 |
|---|---|
| 射擊閃避階段 | 主角被客人丟出的攻擊物(蘋果 / 菸灰缸)命中 |
| 強盜對決階段 | 桌子掩體已摧毀後,主角被強盜子彈命中 |

**不會記失誤的情況**

- 漏接酒器(只中斷連擊)。
- 強盜子彈擊中仍完好的桌子(由桌子耐久吸收)。

**判定流程**

```
攻擊物 / 強盜子彈 命中主角所在格
        │
        ▼
   主角是否有掩體保護?
   ├─ 有(桌子未摧毀)─► 扣桌子耐久,不記失誤
   └─ 無 ─► 記 1 次失誤 ─► 播放失誤音效 ─► 連擊歸零
                │
                ▼
        失誤數 ≥ 上限? ── 是 ──► GAME OVER
                │
                否 ─► 短暫無敵後繼續
```

**附註**:中彈瞬間的「失誤音效」是本類型遊戲的標誌記憶點,需做出高辨識度、與其他音效明顯區隔的聲音,列為音效驗收重點。

## 6. 槍戰(對決)機制

對決出現在每關第 3 階段尾段,是一場「掩體耐久」對「玩家輸出」的賽跑。

**流程**

1. 強盜入場(與牆面通緝令呼應的演出)。
2. 主角自動進入桌後掩體狀態。
3. 雙方互射:
   - 強盜依等級對應的射擊間隔開火;子彈命中桌子則扣桌子耐久。
   - 玩家探身開槍,命中強盜累積有效命中數。
4. 結算:
   - **玩家先達成擊倒命中數** → 強盜倒下,獲得獎勵分,進入下一關。
   - **桌子先被打爛(耐久歸零)** → 掩體消失,玩家暴露;此後再被強盜擊中即記失誤。

**核心張力**:`桌子剩餘耐久` 與 `玩家累積命中` 兩個計量同時逼近終點,玩家必須在掩體撐住的時間內打出足夠輸出。

**難度變化**:隨等級提升,強盜射擊間隔縮短(掩體耗損更快),迫使玩家提高反應與命中效率。

## 7. 關卡結構(10 等級 × 3 關 = 30 關)

**設計原則**

- **等級之間**:換背景主題與配色、強盜外觀升級、速度與密度倍率遞增(三者並用)。
- **等級之內的 3 關**:固定為「階段 A 射擊基礎 → 階段 B 閃避加重 → 階段 C 混合 + 強盜對決」的遞進,過關門檻逐關提高。

**30 關總表**

| 等級 | 背景主題 | 強盜外觀 | 速度倍率 | 攻擊頻率倍率 | 關卡內容(3 關 = A / B / C) |
|---|---|---|---|---|---|
| L1 | 白天酒吧 | 基礎強盜 | 1.0 | 1.0 | A 射擊基礎 / B 閃避加重 / C 混合+對決 |
| L2 | 午後酒吧 | 基礎強盜 | 1.1 | 1.2 | 同上,門檻+5% |
| L3 | 黃昏酒吧 | 基礎強盜 | 1.2 | 1.4 | 同上,新增雙重投擲 |
| L4 | 夜晚酒吧 | 戴帽強盜 | 1.3 | 1.6 | 同上,攻擊物軌跡變化 |
| L5 | 雨夜酒吧 | 戴帽強盜 | 1.4 | 1.8 | 同上,對決加入第二掩蔽點 |
| L6 | 沙塵酒吧 | 戴帽強盜 | 1.6 | 2.0 | 同上,酒器拋速不規律 |
| L7 | 礦鎮酒吧 | 持雙槍強盜 | 1.7 | 2.2 | 同上,強盜射速明顯加快 |
| L8 | 廢棄酒吧 | 持雙槍強盜 | 1.9 | 2.3 | 同上,攻擊物密度高峰 |
| L9 | 風暴酒吧 | 持雙槍強盜 | 2.0 | 2.4 | 同上,桌子初始耐久 -1 |
| L10 | 決戰酒吧 | 頭目強盜 | 2.2 | 2.5 | 同上,對決需擊倒頭目(命中數 +2) |

**過關門檻範例(階段命中數)**

| 等級區間 | 階段 A | 階段 B | 階段 C |
|---|---|---|---|
| L1–L3 | 10 | 15 | 20 |
| L4–L7 | 12 | 18 | 24 |
| L8–L10 | 15 | 22 | 30 |

**每一關各自的新素材呈現**

- **L1 三關**:建立基礎素材——白天背景、基礎強盜、杯/瓶/碟、蘋果/菸灰缸。
- **每升一等級**:必出一張新背景場景 + 對應配色;L4 / L7 / L10 額外新增一款強盜外觀。
- **L5 起**:對決新增第二掩蔽點,需要強盜在新位置的掩蔽 / 探身素材。
- **L10**:頭目強盜為獨立一套素材(入場、掩蔽、探身、中彈、擊倒)。
